# Показания и счета

Этот блок отвечает за коммунальные показания и счета.

На фронте:
- `frontendd/src/app/(app)/meter-readings` - основная зона показаний.
- `frontendd/src/app/(app)/meter-readings/page-resident.tsx` - вид жильца.
- `frontendd/src/app/(app)/meter-readings/page-manager.tsx` - вид менеджера.
- `frontendd/src/app/(app)/meter-readings/owner-landlord/page.tsx` - вид владельца.
- `frontendd/src/app/(app)/meter-readings/invoices/page.tsx` - счета.
- `frontendd/src/app/(app)/debts/page.tsx` - долги.
- `frontendd/src/shared/api/meters.ts` - API показаний.
- `frontendd/src/shared/api/billing.ts` - API счетов.

На беке:
- `back-end/src/modules/meter-readings`
- `back-end/src/modules/invoices`
- `back-end/src/modules/emails`

Что умеет блок показаний:
- показать список показаний;
- принять новое показание;
- изменить показание;
- удалить показание;
- отправить тестовое напоминание.

Что умеет блок счетов:
- создать счет;
- показать счета по компании, квартире или пользователю;
- изменить счет;
- удалить счет.

Адресат счета:
- счет может иметь `recipientType`;
- допустимые значения: `general`, `owner`, `tenant`;
- если `recipientType` не передан, используется `general`;
- обычная квартира использует только `general`;
- отдельные `owner` и `tenant` доступны только для квартиры с `selfManagement: true`;
- `tenant`-счет можно загрузить только если в квартире есть активный арендатор;
- если для квартиры включены два счета, но активного арендатора нет, создается один счет владельцу (`recipientType=owner`);
- если для квартиры включены два счета и активный арендатор есть, можно загрузить два отдельных счета: `owner` для владельца и `tenant` для арендатора;
- уникальность `externalId` для таких счетов считается с учетом `recipientType`, поэтому один внешний номер можно использовать отдельно для владельца и арендатора;
- `GET /invoices` поддерживает фильтр `recipientType`.

Пример загрузки счета арендатора:

```txt
POST /invoices/upload
file=invoice.pdf
buildingId=...
apartmentId=...
period=2026-09
invoiceDate=2026-09-24
amount=120.50
currency=EUR
externalId=erp-2026-09-apt-12
status=issued
recipientType=tenant
```

Пример загрузки счета владельцу:

```txt
POST /invoices/upload
file=invoice-owner.pdf
buildingId=...
apartmentId=...
period=2026-09
invoiceDate=2026-09-24
amount=80.00
currency=EUR
externalId=erp-2026-09-apt-12
status=issued
recipientType=owner
```

Связи:
- квартира из [[Дома и квартиры]];
- пользователь и роль из [[Авторизация]];
- напоминания могут идти через email;
- уведомления связаны с [[Уведомления]].

Типовой сценарий:

Жилец открывает страницу показаний -> вводит значения -> фронт отправляет `/meter-readings` -> бек сохраняет показание -> dashboard и счета получают новые данные.
