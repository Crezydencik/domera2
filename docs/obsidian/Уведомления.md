# Уведомления

Уведомления показывают пользователю важные события.

На фронте:
- `frontendd/src/app/(app)/notifications/page.tsx` - страница уведомлений.
- `frontendd/src/shared/api/notifications.ts` - API уведомлений.
- `frontendd/src/shared/hooks/use-app-notifications.ts` - загрузка и состояние уведомлений.
- `frontendd/src/shared/hooks/use-notifications.ts` - toast-уведомления.
- `frontendd/src/components/toast-provider.tsx` - контейнер toast.

На беке:
- `back-end/src/modules/notifications`

Что умеет фронт:
- показать список уведомлений;
- показать toast;
- обновить настройки;
- отметить уведомление прочитанным.

Что умеет бек:
- вернуть список уведомлений;
- создать уведомление;
- вернуть настройки;
- изменить настройки;
- отметить одно уведомление прочитанным;
- отметить все прочитанными;
- удалить уведомление.

Связи:
- пользователь приходит из [[Авторизация]];
- права зависят от [[Роли и доступ]];
- события могут приходить из [[Показания и счета]], [[Дома и квартиры]], [[Новости и документы]].

Основные API:
- `/notifications`
- `/notifications/settings`
- `/notifications/:notificationId/read`
- `/notifications/read-all`
