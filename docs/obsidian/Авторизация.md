# Авторизация

Авторизация отвечает за вход, регистрацию, сессию, роли и восстановление пароля.

На фронте:
- `frontendd/src/app/(auth)/login/page.tsx` - страница входа.
- `frontendd/src/app/(auth)/register/page.tsx` - регистрация.
- `frontendd/src/app/(auth)/register/verify/page.tsx` - код подтверждения.
- `frontendd/src/app/(auth)/forgot-password/page.tsx` - запрос восстановления.
- `frontendd/src/app/(auth)/reset-password/page.tsx` - новый пароль.
- `frontendd/src/app/(auth)/reset-password/confirm/page.tsx` - подтверждение нового пароля.
- `frontendd/src/app/confirm-email/page.tsx` - подтверждение смены email.
- `frontendd/src/shared/api/auth.ts` - запросы к auth API.
- `frontendd/src/shared/lib/auth-client.ts` - клиентская auth-логика.
- `frontendd/src/shared/lib/auth-session.ts` - работа с сессией.
- `frontendd/src/proxy.ts` - проверка доступа перед открытием страниц.

На беке:
- `back-end/src/modules/auth`
- `back-end/src/modules/users`
- `back-end/src/common/auth`

Основные auth-endpoint'ы:
- `POST /auth/login` - вход по email и паролю.
- `POST /auth/register` - завершение регистрации.
- `POST /auth/register-email-code/request` - запрос кода регистрации.
- `POST /auth/register-email-code/verify` - проверка кода регистрации.
- `POST /auth/session` и `DELETE /auth/session` - создать и удалить серверную сессию.
- `POST /auth/send-password-reset` - отправить письмо/код на сброс пароля.
- `POST /auth/preview-password-reset` - проверить токен перед сменой пароля.
- `POST /auth/confirm-password-reset` - подтвердить новый пароль.
- `PATCH /auth/me/email` и `POST /auth/me/email/confirm` - смена email.
- `PATCH /auth/me/password` - смена пароля в кабинете.
- `GET /auth/account-catalog` - справочник типов аккаунтов для регистрации.
- `GET /auth/docs-login` и `POST /auth/docs-login` - вход для document flow.

Что происходит при входе:
1. Пользователь вводит email и пароль.
2. Фронт отправляет `/auth/login`.
3. Бек проверяет пользователя через [[Firebase]].
4. Бек возвращает данные пользователя.
5. Фронт создает сессию через `/auth/session`.
6. Пользователь попадает в кабинет.

Что происходит при регистрации:
1. Пользователь вводит данные.
2. Фронт может запросить справочник через `/auth/account-catalog`.
3. Фронт запрашивает код регистрации.
4. Бек проверяет email и отправляет письмо через email-модуль.
5. Пользователь вводит код.
6. Фронт отправляет `/auth/register`.
7. Бек создает пользователя, профиль и при необходимости связывает его с приглашением.

Что происходит при восстановлении:
1. Фронт вызывает `/auth/send-password-reset`.
2. Пользователь открывает ссылку или код сброса.
3. Фронт заранее проверяет токен через `/auth/preview-password-reset`.
4. Новый пароль подтверждается через `/auth/confirm-password-reset`.
