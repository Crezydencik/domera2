# Авторизация

Авторизация отвечает за вход, регистрацию, сессию, роли и восстановление пароля.

На фронте:
- `frontendd/src/app/(auth)/login/page.tsx` - страница входа.
- `frontendd/src/app/(auth)/register/page.tsx` - регистрация.
- `frontendd/src/app/(auth)/register/verify/page.tsx` - код подтверждения.
- `frontendd/src/app/(auth)/forgot-password/page.tsx` - запрос восстановления.
- `frontendd/src/app/(auth)/reset-password/page.tsx` - новый пароль.
- `frontendd/src/shared/api/auth.ts` - запросы к auth API.
- `frontendd/src/shared/lib/auth-client.ts` - клиентская auth-логика.
- `frontendd/src/shared/lib/auth-session.ts` - работа с сессией.
- `frontendd/src/proxy.ts` - проверка доступа перед открытием страниц.

На беке:
- `back-end/src/modules/auth`
- `back-end/src/modules/users`
- `back-end/src/common/auth`

Что происходит при входе:
1. Пользователь вводит email и пароль.
2. Фронт отправляет `/auth/login`.
3. Бек проверяет пользователя через [[Firebase]].
4. Бек возвращает данные пользователя.
5. Фронт создает сессию через `/auth/session`.
6. Пользователь попадает в кабинет.

Что происходит при регистрации:
1. Пользователь вводит данные.
2. Фронт запрашивает код регистрации.
3. Бек отправляет письмо через email-модуль.
4. Пользователь вводит код.
5. Фронт отправляет регистрацию на бек.
6. Бек создает пользователя и профиль.
