# Firebase

Firebase - это внешний сервис, через который бек работает с пользователями и данными.

В проекте Firebase спрятан за сервисом:
- `back-end/src/common/infrastructure/firebase/firebase-admin.service.ts`

Модуль:
- `back-end/src/common/infrastructure/firebase/firebase-admin.module.ts`

Зачем нужен Firebase:
- хранить пользователей;
- проверять auth token;
- читать и писать данные;
- работать с коллекциями компании, домов, квартир, счетов, уведомлений;
- помогать беку понимать, кто делает запрос.

Кто использует Firebase:
- [[Авторизация]]
- [[Дома и квартиры]]
- [[Показания и счета]]
- [[Уведомления]]
- [[Приглашения]]
- [[Новости и документы]]
- [[Бек - модули]]

Важно:
- фронт не должен напрямую ходить в Firebase;
- фронт идет в API;
- API идет в Firebase через бек;
- так проще контролировать права и безопасность.
