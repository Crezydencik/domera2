# Фронт - что видит пользователь

Фронт - это все, что пользователь видит в браузере.

В этом проекте фронт сделан на Next.js и лежит в папке `frontendd`.

За что отвечает фронт:
- рисует страницы и меню;
- показывает таблицы домов, квартир, жильцов, счетов;
- собирает данные из форм;
- отправляет запросы на бек;
- показывает ошибки, загрузку, toast-уведомления;
- прячет страницы, если роль пользователя не подходит.

Главные папки:
- `frontendd/src/app` - страницы приложения.
- `frontendd/src/components` - общие компоненты интерфейса.
- `frontendd/src/components/ui` - кнопки, input, modal, dialog.
- `frontendd/src/shared/api` - функции, которые вызывают бек.
- `frontendd/src/shared/lib` - общая логика: routes, auth, server API.
- `frontendd/src/shared/hooks` - React hooks.

Как фронт связан с беком:
- страницы берут данные через [[Фронт - запросы к API]];
- API-файлы вызывают адреса из [[Бек - адреса API]];
- бек отвечает через [[Связь фронта и бека]].

Что смотреть первым:
- [[Фронт - страницы]]
- [[Авторизация]]
- [[Дома и квартиры]]
- [[Показания и счета]]

Когда ищешь ошибку на фронте:
- сначала найди страницу в `frontendd/src/app`;
- потом посмотри, какой файл из `frontendd/src/shared/api` она вызывает;
- потом переходи к нужному модулю на беке через [[Бек - модули]].
