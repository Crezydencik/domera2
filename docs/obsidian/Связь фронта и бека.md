# Связь фронта и бека

Это главная связь проекта.

Фронт показывает экран, но сам не решает бизнес-логику.

Бек принимает решение, проверяет права и работает с данными.

Простой путь запроса:

1. Пользователь нажимает кнопку.
2. Страница фронта вызывает функцию из [[Фронт - запросы к API]].
3. Функция делает HTTP-запрос на адрес из [[Бек - адреса API]].
4. Бек принимает запрос в controller.
5. Бек выполняет логику в service.
6. Service обращается к [[Firebase]].
7. Бек возвращает JSON.
8. Фронт обновляет интерфейс.

Пример с квартирами:

`frontendd/src/app/(app)/apartments` -> `frontendd/src/shared/api/apartments.ts` -> `/apartments` -> `back-end/src/modules/apartments`.

Пример с входом:

`/login` -> `auth.ts` -> `/auth/login` -> `auth.controller.ts` -> `auth.service.ts` -> [[Firebase]].

Пример с показаниями:

`/meter-readings` -> `meters.ts` -> `/meter-readings` -> `meter-readings.service.ts`.

Что важно при отладке:
- если кнопка не работает, смотри сначала фронт-страницу;
- если запрос уходит, но ошибка в ответе, смотри API-файл и бек-контроллер;
- если права не пускают, смотри [[Роли и доступ]];
- если данные странные, смотри [[Данные - простая схема]] и [[Firebase]].
