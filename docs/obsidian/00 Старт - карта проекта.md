# Старт - карта проекта

Эта папка - простая карта проекта Domera для Obsidian.

Смотри на проект как на три слоя:

1. [[Фронт - что видит пользователь]] - браузер, страницы, формы, кнопки.
2. [[Связь фронта и бека]] - запросы, API, cookies, ответы сервера.
3. [[Бек - что делает сервер]] - проверка прав, бизнес-логика, Firebase, письма.

Главная цепочка почти любого действия:

Пользователь на странице -> фронт вызывает API -> бек проверяет пользователя -> бек читает или меняет данные -> фронт показывает результат.

Основные карты:
- [[Фронт - страницы]] - какие экраны есть в приложении.
- [[Фронт - запросы к API]] - какие frontend-файлы вызывают сервер.
- [[Бек - модули]] - из каких частей состоит сервер.
- [[Бек - адреса API]] - какие URL принимает сервер.
- [[Данные - простая схема]] - как связаны компании, дома, квартиры, жильцы, счета.
- [[Роли и доступ]] - кто что может делать.
- [[Основные сценарии]] - готовые цепочки действий.

Бизнес-блоки:
- [[Авторизация]] - вход, регистрация, сессия, пароль.
- [[Дома и квартиры]] - здания, квартиры, владельцы, жильцы.
- [[Показания и счета]] - счетчики, показания, invoices, долги.
- [[Уведомления]] - список уведомлений и настройки.
- [[Приглашения]] - ссылки-приглашения для жильцов и компании.
- [[Новости и документы]] - объявления и документы.

Где лежит код:
- фронт: `frontendd`
- бек: `back-end`
- заметки: `docs/obsidian`

Если граф показывает странные узлы вроде `README`, `LICENSE`, `aria-role`, смотри [[Как смотреть граф]].
