# Приглашения

Приглашения нужны, чтобы подключать людей к системе.

Есть два типа:
- приглашение в квартиру;
- приглашение в компанию.

На фронте:
- `frontendd/src/app/(auth)/accept-invitation/page.tsx`
- `frontendd/src/shared/api/invitations.ts`
- `frontendd/src/shared/api/apartments.ts`

На беке:
- `back-end/src/modules/invitations`
- `back-end/src/modules/company-invitations`
- `back-end/src/modules/emails`
- `back-end/src/common/utils/invitation-token.ts`

Сценарий приглашения жильца:
1. Владелец или менеджер выбирает квартиру.
2. Фронт вызывает API приглашения.
3. Бек создает token.
4. Бек отправляет письмо.
5. Пользователь открывает ссылку.
6. Фронт открывает `/accept-invitation`.
7. Пользователь принимает приглашение.
8. Бек связывает пользователя с квартирой или компанией.

Связано с:
- [[Авторизация]]
- [[Дома и квартиры]]
- [[Роли и доступ]]
- [[Бек - адреса API]]

Почему это важно:
- без приглашений нельзя нормально связать реального пользователя с квартирой или компанией;
- токен нужен, чтобы приглашение было безопасным и проверяемым.
