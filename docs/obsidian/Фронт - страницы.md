# Фронт - страницы

Страницы - это то, что открывается по URL в браузере.

Они лежат в `frontendd/src/app`.

Публичные страницы:
- `/` - стартовая страница.
- `/privacy-policy` - политика приватности.
- `/terms-of-use` - условия использования.
- `/confirm-email` - подтверждение смены email.
- `/invoices/public/[token]` - публичный просмотр счета по токену.
- `/pdf/[token]` - публичный PDF-маршрут по токену.

Страницы входа и регистрации:
- `/login` - вход.
- `/register` - регистрация.
- `/register/verify` - проверка кода регистрации.
- `/forgot-password` - запрос восстановления пароля.
- `/reset-password` - ввод нового пароля.
- `/reset-password/confirm` - подтверждение нового пароля по коду.
- `/accept-invitation` - принятие приглашения.

Страницы кабинета:
- `/dashboard` - главный экран после входа.
- `/platform-users` - пользователи платформы.
- `/approvals` - согласование счетов и загрузок.
- `/admin-buildings` - админ-режим по домам.
- `/platform-billing` - биллинг платформы.
- `/buildings` - дома.
- `/apartments` - квартиры.
- `/apartments/[apartmentId]` - карточка квартиры.
- `/residents` - жильцы.
- `/invoices` - счета.
- `/electricity` - поток по электричеству и оплатам.
- `/meter-readings` - показания счетчиков.
- `/meter-readings/invoices` - связанный экран счетов внутри блока показаний.
- `/meter-readings/management-company` - режим управляющей компании.
- `/meter-readings/owner-landlord` - режим владельца/арендодателя.
- `/debts` - долги и счета.
- `/documents` - документы и новости.
- `/notifications` - уведомления.
- `/support` - поддержка.
- `/settings` - настройки аккаунта и компании.

Что важно:
- доступ к страницам проверяет `frontendd/src/proxy.ts`;
- список маршрутов лежит в `frontendd/src/shared/lib/routes.ts`;
- права ролей лежат в `frontendd/src/shared/api/access.ts`.
