# Основные сценарии

Эта заметка показывает проект как цепочки действий.

## Вход

Пользователь открывает `/login`.

Фронт вызывает `/auth/login`.

Бек проверяет пользователя через [[Firebase]].

Фронт создает сессию и открывает dashboard.

Связано с [[Авторизация]] и [[Роли и доступ]].

## Регистрация

Пользователь вводит данные.

Фронт запрашивает код регистрации.

Бек отправляет письмо.

Пользователь вводит код.

Бек создает пользователя и профиль.

Связано с [[Авторизация]].

## Создать дом

Пользователь открывает `/buildings`.

Фронт вызывает `/buildings`.

Бек проверяет роль.

Бек создает дом в Firebase.

Связано с [[Дома и квартиры]].

## Добавить квартиру

Пользователь открывает `/apartments`.

Фронт вызывает `/apartments`.

Бек создает квартиру и связывает ее с домом.

Связано с [[Дома и квартиры]].

## Пригласить жильца

Пользователь выбирает квартиру.

Фронт вызывает API приглашения.

Бек создает token и отправляет письмо.

Жилец открывает ссылку и принимает приглашение.

Связано с [[Приглашения]].

## Подать показания

Жилец открывает `/meter-readings`.

Фронт отправляет `/meter-readings`.

Бек сохраняет показание.

Данные появляются в кабинете.

Связано с [[Показания и счета]].

## Посмотреть уведомления

Фронт вызывает `/notifications`.

Бек возвращает список уведомлений текущего пользователя.

Фронт показывает их на странице и в toast.

Связано с [[Уведомления]].
