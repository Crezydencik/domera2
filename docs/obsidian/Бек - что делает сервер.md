# Бек - что делает сервер

Бек - это серверная часть на NestJS.

Код лежит в `back-end`.

Главная задача бека - принимать запросы от фронта и выполнять настоящую работу:
- проверять, кто пользователь;
- проверять роль и права;
- читать данные;
- создавать и менять записи;
- отправлять письма;
- считать и отдавать данные для dashboard;
- защищать API от лишних запросов;
- писать audit log.

Главные папки:
- `back-end/src/modules` - бизнес-модули.
- `back-end/src/common` - общие guard, роли, Firebase, audit log, rate limit.
- `back-end/src/app.module.ts` - место, где модули подключаются вместе.
- `back-end/src/main.ts` - запуск сервера.

В NestJS обычно так:
- controller принимает HTTP-запрос;
- service выполняет логику;
- dto описывает входные данные;
- module собирает controller и service вместе.

Пример:

`/apartments` -> `apartments.controller.ts` -> `apartments.service.ts` -> Firebase.
