# Дома и квартиры

Это один из главных бизнес-блоков проекта.

Он описывает структуру жилья:

Компания -> дома -> квартиры -> жильцы и владельцы.

На фронте:
- `frontendd/src/app/(app)/buildings` - экран домов.
- `frontendd/src/app/(app)/apartments` - экран квартир.
- `frontendd/src/app/(app)/apartments/[apartmentId]` - карточка квартиры.
- `frontendd/src/shared/api/buildings.ts` - запросы домов.
- `frontendd/src/shared/api/apartments.ts` - запросы квартир.

На беке:
- `back-end/src/modules/buildings` - дома.
- `back-end/src/modules/apartments` - квартиры.
- `back-end/src/modules/resident` - данные жильца.
- `back-end/src/modules/users` - пользователи.

Что умеет блок домов:
- показать список домов;
- создать дом;
- изменить дом;
- удалить дом;
- проверить, можно ли создавать новые дома.

Что умеет блок квартир:
- показать список квартир;
- создать квартиру;
- изменить квартиру;
- импортировать квартиры;
- назначить владельца;
- пригласить жильца;
- удалить жильца;
- посмотреть audit logs;
- показать storage summary.

Связи:
- жильцы приходят из пользователей;
- приглашения идут через [[Приглашения]];
- показания счетчиков идут через [[Показания и счета]];
- права зависят от [[Роли и доступ]].
