# Новости и документы

Этот блок отвечает за объявления, новости и документы.

На фронте:
- `frontendd/src/app/(app)/documents/page.tsx`
- `frontendd/src/shared/api/news.ts`
- `frontendd/src/shared/api/documents.ts`

На беке:
- `back-end/src/modules/news`
- `back-end/src/modules/documents`

Что умеет бек по новостям:
- вернуть список новостей;
- вернуть одну новость;
- создать новость;
- изменить новость;
- удалить новость.

Что умеет бек по документам:
- вернуть список документов;
- загрузить документ;
- скачать документ;
- удалить документ;
- изменить доступ к документу.

Что важно:
- документы больше не привязаны к `/news`, для них есть отдельный `documents` модуль;
- в карточке квартиры документы участвуют отдельно от новостей;
- для открытия файла используется download-маршрут, а не обычный JSON-ответ.
